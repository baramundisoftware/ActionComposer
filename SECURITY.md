# Security policy

Action Composer is a community project by baramundi colleagues. It is not an official
baramundi product. Security reports are still taken seriously.

## Report a vulnerability privately

Use GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/baramundisoftware/ActionComposer/security) of this repository.
2. Choose **Report a vulnerability**, or go straight to the
   [report form](https://github.com/baramundisoftware/ActionComposer/security/advisories/new).
3. Describe what you found, the version of Action Composer, and how to reproduce it.

Only the maintainers can read the report. Please do not open a public issue, a discussion
or a pull request for a vulnerability, and do not post details anywhere public until a fix is out.

Do not include real passwords, API keys, tokens, server names or customer data in a report.
A description, and a minimal example with made-up names, is enough.

## What to expect

This is a community project, so there is no guaranteed response time. The maintainers will
read the report, say whether they can reproduce it, and publish a fixed release and an advisory
that credits you, if you wish.

## Which versions are covered

The latest release. Older releases are not patched: update to the newest one.

## Out of scope

- Problems in baramundi Management Suite itself. Report those to baramundi through the usual support channel.
- Findings that need an attacker who already has administrator rights on the computer running Action Composer.
